Keep each project as one content entry, then use the same fields to generate its work card and detail page.

CMS setup outline
  1. Move project content into one Markdown file per project, named with its URL slug.
  2. Use fields for title, category, scope, summary, cover image, and gallery images with alt text.
  3. Render the work grid and detail pages from shared templates so each project is only entered once.
  4. Add Decap CMS at /admin for browser-based editing; it can commit content and uploaded images to the site's Git repository.

For this static portfolio, Astro content collections plus Decap CMS is a lightweight path. The current pages are still hand-edited HTML; this outline describes the next CMS step.
