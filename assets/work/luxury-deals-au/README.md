Place exported gallery images for Luxury Deals AU in this folder, for example `01.webp` and `02.webp`.

Then add them to the Luxury Deals AU entry in `js/portfolio-data.js`:

```js
gallery: [
  { src: "/assets/work/luxury-deals-au/01.webp", alt: "Luxury Deals AU campaign image" },
  { src: "/assets/work/luxury-deals-au/02.webp", alt: "Luxury Deals AU product detail" },
],
```

Edit that entry's `category`, `scope`, and `summary` in the same file.
